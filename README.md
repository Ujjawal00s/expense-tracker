
# Expense Tracker

A full-stack web application to manage personal finances and track income and expenses.

## Features
- User registration and login
- Dashboard with income, expenses and balance
- Add, edit and delete transactions
- Search and filter transactions
- Budget management
- Reports and profile pages

## Tech Stack
- Frontend: React.js, JavaScript, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB

## Project Structure
- `frontend/` — React application
- `backend/` — Express API and database models

## Getting Started
1. Clone this repository.
2. Install frontend and backend dependencies using `npm install` in each folder.
3. Configure your backend environment variables in `backend/.env`.
4. Start the backend and frontend using the scripts defined in their respective `package.json` files.
